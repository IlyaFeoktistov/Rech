# Rech (Речь)

Язык программирования, в котором русская грамматика, морфология и
словообразование становятся частью синтаксиса и семантики.

```
функция главная
{
    вывести "Привет, мир!"
}
```

## С чего начать

- **[Руководство](MANUAL.md)** - язык последовательно, от простого к
  сложному: философия, синтаксис, примеры. Начните отсюда, если видите
  Rech впервые.
- **[Спецификация](SPEC.md)** - формальное описание того, что компилятор
  принимает **прямо сейчас** - справочник, не учебник.
- **[Справочник](REFERENCE.md)** - каждая встроенная функция, тип/сущность
  и ключевое слово одной строкой - для быстрого поиска, не для чтения
  подряд.
- **[Грамматика (черновик)](GRAMMAR.md)** - синтаксис того, что
  запланировано, но ещё не реализовано.
- **[Морфологический движок](MORPHOLOGY.md)** - как устроено падежное
  сопоставление ключевых слов под капотом.

Установка компилятора, сборка примеров, структура репозитория - в
`README.md` в корне репозитория.
